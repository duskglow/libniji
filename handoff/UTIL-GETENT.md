## Probe-settled (reference, black box)

Columns: hosts/ahosts address `%-15s`; services, protocols, networks, netgroup, initgroups name `%-21s`; rpc
`%-15s %d` then, if aliases, one extra space; aliases `name:` padded to 15 then a space, members `, `-joined.
`Unknown database: X` and `wrong number of arguments` on stderr with the Try line on STDOUT (exit 1); option errors
on stderr with the Try line on stderr (exit 64); `-s db:svc` with an unknown db: `getent: Unknown database name`,
exit 1. Numeric keys are whole decimal (`+1000`, `01000` yes; `0x3e8`, `1000x` are names). netgroup: 1 key lists
(missing: exit 2), exactly 4 keys run innetgr with `-` literal and print `= 0|1`, any other count prints nothing,
exit 0; an empty host field prints as a space. initgroups lists unknown users with no groups, exit 0. `-V`/`--help`
win wherever they appear.
