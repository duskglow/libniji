## Fixed in run 2 (do not redo)
* The check counted ids to pick the shorter configs spelling; the probe compares string lengths, so real tables
  failed it. The check now derives the probe's exact spelling (`configs_form`: `*`, ids, or `!`+missing ids,
  shorter string, ids on a tie) and requires it; an empty set is an error.
* `appendix_c.py` had an unterminated string in the C.12 text (SyntaxError).
* Keyword pass: with `-undef` alone GCC still pre-includes stdc-predef.h, so `_STDC_PREDEF_H` and
  `__STDC_ISO_10646__` were taken for keywords and never probed (the check reported `_STDC_PREDEF_H` visible
  nowhere). Now `-undef -nostdinc`. Keywords also get the `#ifdef` test alone, so `true`/`false` (stdbool-style
  macros before C23) and `thread_local` (threads.h) are recorded; the check no longer exempts true/false.
