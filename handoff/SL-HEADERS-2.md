## Done
* `spec/tools/header_probe.py`: compile-only probe (plan/headers.md §2.2). Reads back only exit statuses and the
  line numbers of errors in its own file. Pass A: `#ifdef` (error on `#error` = macro), then every candidate
  `#undef`ed, `struct vis_g_N; extern struct vis_g_N N;` (error = declared ordinary name; undeclared names cost
  no diagnostic: the first design used `__typeof__(N)` and GCC's spelling hints made one unit take ~10 min),
  `sizeof(struct|union|enum N)` for tags. Pass B classifies declared names (typedef `sizeof(N *)`, function
  `(0,N)` vs `&N` types, enumerator `enum { e = (N) }`); C++ variants in the code. 40 configurations
  (`-std=c++26` dropped: GCC 13.3 has none). Candidates: prototypes/constants/versions OBJECT/layouts names,
  type names in declarations, and backticked identifiers of the functional spec (13234 names + 146 tags).

  (`cmp`), 243 headers, 69868 rows, 216 include-error rows (e.g. `_TIME_BITS=64` alone fails everywhere).
  They used the old explicit config lists (15 MB); the encoding is now `*` / ids / `!`+excluded ids (5.2 MB).
