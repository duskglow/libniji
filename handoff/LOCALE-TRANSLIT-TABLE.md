## What the branch does

* Probe (black box, reference system: `tools/probe/translit_probe.c`, `tools/probe/translit_table.py`): iconv
  `<codeset>//TRANSLIT` of every code point 1..0x10FFFF the codeset lacks, under each of the 182 legacy-codeset
  locales of the reference plus en_US.utf8 for ASCII. `default_missing` (U+E000's result: `?` in most, empty in
  ku_TR/tr_CY/tr_TR) is left out (an entry giving it cannot be told apart). Vote: a code point is in the shared
  table when most locales lacking it give a result (2,419 entries); alternatives ordered so each codeset's result
  comes first (one cycle, U+FB4F, harmless). Per-locale rows only where a locale's own strings hold a code point its
  table treats otherwise: ro_RO U+021B to U+0163; uz_UZ U+02BB, U+0419, U+0439, U+04B2, U+04B3.
* Data: `spec/locale-probe/translit.tsv` (@generated by tools/probe/translit_table.py).
* Generator: `xtask/src/locale_probe.rs` (`with_translit`, `translit`, `own_translit`, `in_codeset`; a legacy
  name's own value read as its UTF-8 sibling's text when the table explains the difference: the @euro wide
  separators keep U+202F in the source); `xtask/src/locales.rs` (`translit_shared` source; `ctype`: own entries, then
  `include "translit_shared";""`, then combining, compat). `tools/deb/manifest.tsv` row for translit_shared.
* Tests: xtask `locale_probe::tests::{a_legacy_value_the_table_explains_is_the_siblings_text,
  own_entries_merge_per_source_and_refuse_a_contradiction}`, `locales::tests::sources_take_the_probed_transliterations_shared_and_their_own`;
  `crates/locale/tests/reference.rs` `generated_legacy_codesets_hold_the_references_transliterated_values`.
* Records: `records/decisions/D-31/D-31.33.toml`; `docs/differences-from-glibc.md` rows "Locale sources" and
  "Locale data CLDR does not have".

## Proof (the brief's)

* The 251 values: before (LOCALE-PROBE-GEN-2's measurement) 251 values in 81 of 182 legacy entries differed (`€`
  dropped from ISO-8859-1 `currency_symbol`, `’` dropped from `d’abril`, U+202F/U+00A0 separators). After: the test
  compares every probe row of every legacy entry where it differs from its UTF-8 sibling, 394 values in 86 entries
  (the 251 included), plus those entries' wide thousands separators from the sibling's rows: 560 values, 0 differ
  (job t3, 184 s alone; 414 s in the gate). The per-value table is the test's own comparison (it prints every differing value).
* Remaining (not a compile-time value): run-time `iconv //TRANSLIT` in a generated locale differs from the
  reference's in 38,814 (locale, code point) pairs in 104 of 183 locales with tables of their own (ko_KR.euckr
  10,416, ja_JP.eucjp 4,478, zh_* about 1,500 to 2,100 each, tr_*/ku_TR 1,854, uk_UA 585, el_* 493, ar_* 133).
  Recorded in D-31.33 and the differences row as a gap; a follow-up would emit per-locale tables from the probe.
* Plants: `handoff/LOCALE-TRANSLIT-TABLE.plants` (5: shared table emitted empty, not included, own entries dropped,
  sibling text ignored, alternatives reversed).
