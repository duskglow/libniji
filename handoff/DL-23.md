## Reference probes (black-box, glibc 2.39 on the Skylake-SP build host; probe source: scratch rd.c, not in tree)
- `sizeof(struct r_debug)` 40; offsets map 8, brk 16, state 24, ldbase 32. `r_version` = **1** (spec clause
  s27_4_c_0 says "since 2.35 r_version is 2": the probe shows 1 without `dlmopen`; INFORMATIONAL spec gap).
- `DT_DEBUG` of the program = `&_r_debug` **in ld.so** (not the program's copy), for PIE and non-PIE.
- non-PIE and PIE both get `R_X86_64_COPY _r_debug@GLIBC_2.2.5` when the program names `_r_debug`. The copy is
  a snapshot taken at relocation: its `r_state` stays 1 (RT_ADD) forever, `r_map`/`r_brk`/`r_ldbase` equal
  ld.so's (the head node never changes, so walking the copy's `r_map` shows dlopen'd objects).
- `r_brk` == `dlsym(RTLD_DEFAULT, "_dl_debug_state")`; `r_ldbase` = ld.so's base.
- list: program `""`, `linux-vdso.so.1`, libc by full path, `/lib64/ld-linux-x86-64.so.2` (PT_INTERP), then
  dlopen'd objects; `dl_iterate_phdr` lists the same in the same order; dlopen handle == link map in the list.

## Design (in the code)
- `NODES` (crates/boundary/src/ld/dlopen.rs): every link-map node now lives in a static of ld.so's .bss
  (`NodeSpace`, atomics, CAP x Node), not in the loader's mmap; `Loader.nodes` is a zero-sized `Nodes` that
  derefs to it (all 50 `l.nodes[..]` uses unchanged). Node addresses (= handles) are fixed from start.
- The start (`ld.rs::rendezvous_start`, before relocation) writes each start-time node's public prefix via
  `dlopen::start_node` (pointer writes only), ld.so at its index or appended at `n` (same order as
  `adopt_start` and `readers::fill_start`), then `debug::start` (fills `_r_debug`, writes DT_DEBUG via
  `niji_ld::reloc::dynamic_word`, RT_ADD + `_dl_debug_state()`); after RELRO, before `run_init`,
  `debug::consistent(relro)` (RT_CONSISTENT).
- `l_name` = the path the start opened the object by: the `PathStore` is now kept (no `store.release()`),
  `keep` appends a NUL; an absolute DT_NEEDED is kept in the store too. ld.so's name = program's PT_INTERP.
- `adopt_start` keeps a start-linked node's prefix (`describe(.., prefix=false)`) so the chain is never cut.
- `dl_iterate_phdr` start entries take the link map's name (`dlopen::start_name`): the two agree.
- dlopen publication: RT_ADD before linking, RT_CONSISTENT after `readers::publish`; `close_end`: RT_DELETE
  before the first `unload`, RT_CONSISTENT after the loop.
- Copy: `ProcImage::copy` calls `debug::note_copy`; `consistent` keeps it only when 8-aligned and outside the
  program's RELRO, fills it; `debug::change` writes `r_state` to both. Libniji's copy is kept up to date
  (the brief's requirement) where the reference's copy keeps RT_ADD: needs a differences row (RULING NEEDED:
  recommend no compat option - the stale value carries no information).
- Exports: `xtask/src/so.rs` LD_EXPORTS += `_r_debug`, `_dl_debug_state` (versions from spec/abi/versions.tsv).

## Known gaps (state in hand-back)
