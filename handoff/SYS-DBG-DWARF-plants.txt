# tool's product builds are the system flavour's release products (the -g1 flags are release-only). The product plants
# package target/niji (build.sh --products) and run check-system.sh; the check plants run check-system.sh on next's
# system packages (built by sys-dbg-dwarf-base, copied to /mnt/zram/claude/SYS-DBG-DWARF/base-debs), whose 12 debug
# files have no DWARF, or on packages from a manifest copy in which locale has no strip debug row.
