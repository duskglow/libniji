# INTERNAL-ALLOC-ROUTING-2 plants (D-X.156: the library's own allocations go through a replacing malloc family; the ordinary path makes no routing test of its own)
# no-route: the replacement is never detected, so every internal allocation stays private; x_internal_alloc sees opendir and setlocale make no call to the replacement.
# fast-bound-kept: the decision is made but the allocation fast path keeps its default bound, so the library's allocations stay private.
# release-bound-kept: allocations are routed but their release keeps the default reserve bound, so a replacement's block reaches the heap's free (misuse) instead of the replacement's free.
# locale-query-alloc (setlocale area): the built-in name is interned by allocation again; with every allocation failing, setlocale(LC_ALL, NULL) returns NULL.
# reserve-fallback (opendir area): a refused routed allocation is served from the private reserve; opendir succeeds with every allocation failing and its block reaches the program's free.
# (no-route, fast-bound-kept and release-bound-kept keep the routing words changing: a mutant that leaves them constant lets the compiler fold them, and the products build's start-up state check refuses it before any test runs.)
# printf-int-alloc: a heap table for a plain integer conversion; snprintf's common conversions then call the replacement and fail under refusal.
