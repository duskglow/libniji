   (not in typedefs.tsv or visibility.tsv). Every program using `<iostream>`, `<locale>`, `<sstream>`... fails.
   RULING NEEDED (recorded in the report): the C++ library is the compiler's, not patchable per package.

   wcsrchr, wcsstr, wmemchr: libniji's wchar.h has the [cwchar.syn] const overloads but the C++ library defines its
   own as well; `<cstring>` does not fail. Compare how string.h's overloads are offered to the C++ library and
   do the same for wchar.h (only through the compiler's diagnostics, plan/headers.md 2.2).
