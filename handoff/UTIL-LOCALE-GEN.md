## Probe-settled behaviour (implemented in cmds.rs; cite the probe file)
* locale-gen: every argument except `--keep-existing` ignored; missing /etc/locale.gen: no output, rc 0, archive
  kept. Else the archive is removed (not with --keep-existing, where names already stored are skipped silently),
  stdout `Generating locales (this might take a while)...`, per entry `  <display>...` then localedef's own
  messages then ` done`, finally `Generation complete.`; rc always 0. Line: leading blanks ignored, `#` lines and
  blank lines skipped, locale = first field, charset = rest of line (so `UTF-8 # trailing` is a charmap name);
  no charset: `error: Bad entry '<locale> '`. display = locale without codeset + `.` + charset + `@modifier`;
  localedef runs `-i <locale without codeset> -f <charset> <locale as written>`. Directories in /usr/lib/locale
  untouched. Archive form is the default.
* validlocale: available -> stderr `locale 'X' valid and available`, rc 0 (C, POSIX, C.UTF-8, '' too); else stdout
  `X <SUPPORTED charset | $DEFAULTCHARSET | ISO-8859-1>`, stderr `locale 'X' not available`, rc 1; no argument:
  stdout `Usage: <argv0> <locale>`, rc 1; extra args ignored.
* update-locale: file /etc/locale.conf (/etc/default/locale -> ../locale.conf is made by the postinst); new file
  starts `#  File generated by update-locale`; always rewrites (no args too). Lines `[blanks][#]NAME=value` are
  variables (edited in place, `#`+line to disable, set replaces a commented one); `export X=..` is not; empty line
  -> `#`; new vars appended (reference: hash order; libniji: argument order). `--reset` comments every active var
  not named. Unknown option `Unknown option: x` (stderr, continues, rc 0); `--locale-file` without value
  `Option locale-file requires an argument`. LANGUAGE whose first entry's language differs from LC_ALL's (else
  LANG's) -> stdout warning, disabled, unless that is C/POSIX (C.UTF-8 does warn). Checks (LANG, LC_*): stderr
  `*** update-locale: Error: invalid locale settings:  A=1 B=2`, rc 255, file unchanged (the reference then
  prints a `----------` block with its check program's output: NOT reproduced, say so in D-31.37). Write error:
  `update-locale: Unable to write F: <strerror>` rc 2. `--help`: usage on stderr rc 0.
* Package: conffile only /etc/locale.alias; /usr/share/locale/locale.alias -> /etc/locale.alias; /usr/sbin/{locale-gen,
  update-locale,validlocale}; postinst creates /etc/locale.gen when missing (own header text + `# <entry>` for every
  SUPPORTED line, byte-sorted), /etc/locale.conf + the link. debconf: `locales/locales_to_be_generated`
  (multiselect, `a, b` sorted), `locales/default_environment_locale` (select, `None`); config derives the selection
  from the uncommented /etc/locale.gen lines; postinst rewrites locale.gen (selected entries uncommented, other
  uncommented lines `# `+line, missing SUPPORTED entries appended commented), runs locale-gen, then
  `update-locale LANG=<default>` or (None / default not selected) `update-locale --no-checks LANG`.
