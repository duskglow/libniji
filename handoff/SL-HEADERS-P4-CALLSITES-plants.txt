# Plants of SL-HEADERS-P4-CALLSITES (cargo xtask plants; docs/plants.md). Each drops or changes one declaration the
# story fixed; P4 (validation/headers_p4.py) must fail on it. The products stage the committed libc-include/, so each
# command regenerates the headers and restages them first. Part 2 (callsites/noexcept) runs with --no-cxx, part 1
# (C++ inclusion) with --no-noexcept. The brief's "math.h __ name" plant has no site: ruling #8468 keeps those names
# omitted (D-X.107); the math.h plants drop the isinf function declaration and the C99 functions' exception specs.
# Run 1 (job sl-headers-p4-callsites-plants) also planted __fpending's reserved.tsv row emit -> omit: SURVIVED, by
# design: P4 part 2 leaves out exactly the names reserved.tsv omits (ruling #8468), so a flipped row is a policy change
# P4 cannot see (hand-back INFORMATIONAL). p4cs-fpending-owns drops the same declaration in the template instead.
