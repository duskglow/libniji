## What the branch does

* `xtask/src/locales.rs`: `c_source()` writes the source `C` (`localedef -i C -f UTF-8` = C.UTF-8): `LC_CTYPE`
  copies `i18n`; `LC_COLLATE` is `<U00000000>` `..` `<U0010FFFF>` (equal-width names); POSIX locale values
  (XBD 7.3) in LC_TIME/NUMERIC/MONETARY/MESSAGES; A4, metric; `name_fmt`, `postal_fmt`, `tel_int_fmt` from
  spec/abi/langinfo.tsv's C.UTF-8 column. `write()` emits it in the name list's order, so `SUPPORTED` gains
  `C.UTF-8 UTF-8` (line 64). No transliteration includes (the generated territory locales have them).
* `tools/deb/manifest.tsv`: row for `usr/share/i18n/locales/C`.
* `crates/locale/tests/reference.rs::generated_c_source_compiles_to_the_builtin_c_utf8`: compiles the generated `C`
  for UTF-8 with the library localedef and checks, for every code point below 0x110000, the 12 POSIX classes,
  `combining`, `combining_level3`, toupper/tolower/totitle and width against `niji::unicode` (the built-in), and that
  LC_COLLATE parses as `Collation::CodePoint`. Unit test `c_source_orders_every_code_point_in_one_equal_width_run`.
* differences row "Locale names offered": C.UTF-8 is now offered.
